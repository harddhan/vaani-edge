# Reports

Generated output lands here:

- `evaluation_*.json` - `ml/training/evaluate.py` output.
- `threshold_sweep_*.json` - `ml/training/threshold_sweep.py` output.
- `quant_comparison_*.json`, `quantization_report_*.md` - `ml/quantization/` output.
- `server_metrics_*.json` - per-session latency reports from `server/metrics.py`.
- `debug_wav/*.wav` - reconstructed audio from server sessions (if `logging.debug_save_wav: true`).

Nothing in this directory is committed with real data (see `.gitignore`);
it is regenerated by running the corresponding scripts.
